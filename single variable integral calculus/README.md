# Calculus

This directory contains a collection of LaTeX-typed calculus notes compiled as a concise mathematical reference.

The notes are intended to provide a comprehensive compilation of definitions, identities, standard results, integration techniques, theorems, and formulas in a clean format. They are designed as reference material rather than as a textbook.
